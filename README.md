# 📚 Reading List - 読書記録アプリ

シンプルで使いやすい読書記録アプリです。ブラウザだけで動作し、すべてのデータはローカルに保存されます。

## 🌐 デモサイト

**👉 https://seren34-708.github.io/ReadingList/**

すぐに使えます！アカウント登録不要、完全無料です。

---

## ✨ 主な機能

### 📖 基本機能
- ✅ **本の登録・編集・削除** - タイトル、著者、ジャンル、評価など
- ✅ **ISBN自動入力** - ISBNコードから書籍情報を自動取得
- ✅ **ステータス管理** - 読書中・読了・読みたい
- ✅ **評価システム** - 5段階評価（色分けバッジ表示）
- ✅ **メモ・感想** - 自由にメモを記録

### 🔍 検索・フィルター
- ✅ **全文検索** - タイトル・著者・メモから検索
- ✅ **ステータス絞り込み** - 読書中/読了/読みたい で絞り込み
- ✅ **ジャンル絞り込み** - 8つのジャンルから選択
- ✅ **複合フィルター** - 検索 + ステータス + ジャンルを組み合わせ
- ✅ **並び替え** - 日付・評価・タイトル順など7種類

### 📊 ジャンル（8種類）
1. 📖 小説・文学
2. 📘 ビジネス・経済
3. 💡 自己啓発・心理・哲学
4. 💻 技術・IT
5. 📚 実用書・趣味
6. 🎓 学習・教養
7. 🌍 英語・洋書
8. 📝 その他

### 💾 データ管理
- ✅ **自動保存** - ブラウザのlocalStorageに自動保存
- ✅ **エクスポート** - JSONファイルでバックアップ
- ✅ **インポート** - 他の端末でデータを復元

### 🌍 その他の機能
- ✅ **言語切り替え** - 日本語・English対応
- ✅ **レスポンシブデザイン** - スマホ・タブレット対応
- ✅ **完全オフライン動作** - インターネット不要（ISBN検索以外）

## 🚀 使い方

### 1. アクセスする
```
https://seren34-708.github.io/ReadingList/
```
ブラウザで開くだけで、すぐに使い始められます。

### 2. 本を追加する

#### 方法A: 手動で入力
1. 「本を追加」フォームに情報を入力
2. タイトル（必須）、著者、ジャンル、評価などを記入
3. 「記録を追加」をクリック

#### 方法B: ISBN自動入力（便利！）
1. ISBNコード（13桁または10桁）を入力
   - 例: `9784101001098`
2. 「📚 情報取得」をクリック
3. 書籍情報が自動で入力される
4. 内容を確認して「記録を追加」をクリック

**ISBN検索について:**
- Open Library API と Google Books API を自動で使い分け
- 見つからない場合は手動で入力してください

### 3. 本を管理する

#### 検索・絞り込み
- **検索ボックス**: キーワードを入力して即座に絞り込み
- **ステータス**: 読書中/読了/読みたい で絞り込み
- **ジャンル**: 8つのジャンルから選択
- **クリアボタン**: 検索をリセット

#### 編集・削除
- **編集**: 本のカードの「編集」ボタン → 情報を変更 → 「保存」
- **削除**: 本のカードの「削除」ボタン → 確認 → 削除

### 4. データをバックアップする（重要！）

#### エクスポート
1. 画面下部の「📥 データをエクスポート」をクリック
2. JSONファイルがダウンロードされる
   - ファイル名例: `reading-log-backup_2026-02-09_15-30-00.json`
3. 安全な場所に保存（GoogleドライブやDropboxなど）

#### インポート
1. 「📤 データをインポート」をクリック
2. バックアップしたJSONファイルを選択
3. 確認メッセージで「OK」
4. データが復元される

**⚠️ 重要な注意事項:**
- ブラウザのデータを削除すると記録も消えます
- 定期的（月1回程度）にエクスポートしてバックアップを取ってください
- 複数デバイスで使う場合は、エクスポート/インポートでデータを移行してください

### 📖 読書記録のルーティン
```
【本を読み始めたら】
1. 本を追加
2. ステータス: 読書中
3. 読み始めた日を記録

【本を読み終えたら】
1. 編集ボタンをクリック
2. ステータス: 読了
3. 読み終わった日を記録

5. 感想をメモ欄に書く

【次に読む本を選ぶ】

→ 読みたい本リストから選ぶ
```

### 🌟 高評価の本を探す
```
1. 並び替え: 評価順（高→低）
2. 結果: ★★★★★（金色バッジ）の本が上に表示される
```

### 📚 読了本の振り返り
```
1. ステータス: 読了
2. ジャンル: 小説・文学（例）
3. 並び替え: 評価順（高→低）
→ お気に入りの小説が一目で分かる
```

### 🔍 キーワード検索
```
検索ボックスに入力:
- タイトルの一部（例: 「村上」）
- 著者名（例: 「夏目漱石」）
- メモの内容（例: 「感動」「おすすめ」）
→ リアルタイムで絞り込まれる
```

### 📊 積読の確認
```
ステータス: 読みたい
→ 読む予定の本を一覧表示
→ 何冊積んでいるか確認
```

評価ごとに異なる色のバッジで表示されます：

| 評価 | 表示 | 色 | 意味 |
|------|------|-----|------|
| ⭐⭐⭐⭐⭐ | ★★★★★ | 金色グラデーション | 最高傑作 |
| ⭐⭐⭐⭐ | ★★★★ | オレンジグラデーション | とても良い |

| ⭐ | ★ | 灰色グラデーション | 良くない |

## 🔒 プライバシー・セキュリティ

### データの保存場所
- **保存先**: ブラウザのlocalStorage
- **サーバー送信**: なし（あなたのデータは外部に送信されません）
- **アクセス**: あなただけがデータを見られます

### セキュリティ
- ✅ アカウント登録不要
- ✅ ログイン不要
- ✅ 個人情報の入力不要
- ✅ サーバーにデータを送信しない

### 注意事項

⚠️ **ブラウザのデータを削除すると記録も消えます**
- ブラウザの履歴・Cookie削除に注意
- シークレットモードでは使わない（データが残りません）
- 定期的にエクスポートしてバックアップを取ってください

⚠️ **複数デバイスで自動同期はされません**
- スマホとPCで別々のデータになります
- エクスポート/インポートで手動でデータを移行してください

⚠️ **ブラウザを変えるとデータは別々です**
- Chrome と Firefox は別のlocalStorage
- 同じデータを使いたい場合はエクスポート/インポート

## 💬 よくある質問（FAQ）

### Q1. データはどこに保存されますか？
**A.** ブラウザのlocalStorageに保存されます。サーバーには送信されず、あなたのPC/スマホだけに保存されます。

### Q2. アカウント登録は必要ですか？
**A.** 不要です。ページを開くだけですぐに使い始められます。

### Q3. 料金はかかりますか？
**A.** 完全無料です。今後も無料で使い続けられます。

### Q4. スマホでも使えますか？
**A.** はい。スマホブラウザで快適に使えます。iPhone、Android両方対応しています。

### Q5. オフラインで使えますか？
**A.** はい。ISBN検索以外の機能は完全オフラインで使えます。

### Q6. 複数のデバイスで同期できますか？
**A.** 自動同期はできません。エクスポート/インポート機能で手動で同期してください。

### Q7. ブラウザのデータを削除したらどうなりますか？
**A.** 読書記録も削除されます。定期的にエクスポートしてバックアップを取ることをおすすめします。

### Q8. ISBN検索がエラーになります
**A.** 以下を試してください：
- 1-2分待ってから再試行
- ISBNコードを確認（13桁推奨）
- 別のISBN（ISBN-10/ISBN-13）を試す
- 見つからない場合は手動で入力

### Q9. データをバックアップするにはどうすればいいですか？
**A.** 
1. 「データをエクスポート」でJSONファイルをダウンロード
2. GoogleドライブやDropboxに保存
3. 月1回程度、定期的にバックアップすることをおすすめします

### Q10. 評価の星の色が変わりません
**A.** ページを完全リロードしてください（Ctrl+Shift+R または Cmd+Shift+R）。新しいバージョンでは色付きバッジで表示されます。

### Q11. 他のブラウザにデータを移行したい
**A.** 
1. 元のブラウザで「データをエクスポート」
2. 新しいブラウザでアプリを開く
3. 「データをインポート」でファイルを選択

### Q12. データが消えないか心配です
**A.** 以下の対策をおすすめします：
- 月1回エクスポートしてバックアップ
- バックアップファイルをクラウド（Googleドライブなど）に保存
- 重要な本を追加したらすぐエクスポート
