📝 処理フローの説明

  1. フロントエンドアクセス: ユーザーがS3でホストされているWebサイトにアクセス
  2. 静的コンテンツ配信: index.htmlとJavaScriptがユーザーのブラウザに配信される
  3. API呼び出し: JavaScriptからAPI Gatewayにリクエスト（例: 本の追加）
  4. Lambda起動: API GatewayがLambda関数を実行
  5. 認証情報取得: LambdaがSecrets Managerからデータベース認証情報を取得
  6. データベース操作: LambdaがRDS PostgreSQLにクエリを実行
  7. 結果返却: データベース結果がLambdaを経由してユーザーに返される

🔧 主要コンポーネント

📦 Amazon S3

  • 静的ウェブサイトホスティング
  • index.htmlの配信
  • HTTPS自動対応
  • 高可用性・耐久性

🌐 API Gateway

  • HTTP API (REST)
  • CORSの自動設定
  • Lambda統合
  • スロットリング・レート制限

⚡ AWS Lambda

  • Node.js 18ランタイム
  • 4つの関数（CRUD操作）
  • VPC内で実行
  • 自動スケーリング

🗄️ Amazon RDS

  • PostgreSQL 15.4
  • db.t3.micro インスタンス
  • プライベートサブネット配置
  • 自動バックアップ (7日間)

🔐 Secrets Manager

  • DB認証情報の暗号化保存
  • 自動ローテーション対応
  • Lambda統合
  • 監査ログ

🔒 VPC & セキュリティ

  • プライベート/パブリックサブネット分離
  • マルチAZ構成
  • セキュリティグループによるアクセス制御
  • NACLによるネットワーク保護
