🔄 データフローの説明

  1. ユーザーアクセス: ブラウザからS3の静的ウェブサイトにHTTPSでアクセス
  2. API呼び出し: JavaScriptがAPI GatewayのエンドポイントにHTTPリクエスト
  3. Lambda実行: API GatewayがVPC内のLambda関数を起動
  4. 認証情報取得: LambdaがSecrets ManagerからRDS認証情報を取得
  5. データベースアクセス: LambdaがプライベートサブネットのRDSに接続
  6. SQLクエリ実行: PostgreSQLでCRUD操作を実行
  7. レスポンス返却: 結果がLambda → API Gateway → ユーザーに返される
  8. ログ記録: 全てのアクティビティがCloudWatchに記録される

🔒 セキュリティ対策

  • ネットワーク分離: RDSはプライベートサブネットに配置し、インターネットから直接アクセス不可
  • セキュリティグループ: Lambda-SGからのPort 5432のみ許可
  • 暗号化: 通信は全てHTTPS/TLS、認証情報はSecrets Managerで暗号化
  • 最小権限: IAMロールで必要最小限の権限のみ付与
  • 監査ログ: CloudWatch Logsで全アクティビティを記録
  • VPC Endpoints: Secrets ManagerへはVPC Endpoints経由でプライベート接続

⚡ 高可用性・スケーラビリティ

  • マルチAZ: 2つのAvailability Zoneに分散配置
  • Lambda自動スケーリング: リクエスト量に応じて自動的にスケール
  • RDSバックアップ: 自動バックアップ（7日間保持）
  • NAT Gateway冗長化: 各AZにNAT Gatewayを配置
  • 自動フェイルオーバー: RDS Multi-AZ有効化でDBフェイルオーバー対応
