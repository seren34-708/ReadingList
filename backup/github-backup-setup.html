🔄 GitHub自動バックアップ設定

読書記録を毎週自動的にGitHubにバックアップします

📌 この機能について
GitHub Actionsを使用して、毎週日曜日午前3時に自動的にバックアップを作成し、8週間以上古いバックアップを自動削除します。

📋 セットアップ手順

1 GitHubリポジトリの確認
✅ すでに作成済み: ReadingList
✅ index.html が配置されています
次のステップに進んでください
2 backupフォルダを作成
  1. GitHubの ReadingList リポジトリページを開く
  2. 「Add file」→「Create new file」をクリック
  3. ファイル名に backup/.gitkeep と入力
  4. 「Commit new file」をクリック
  5. これで backup フォルダが作成されます
3 Personal Access Tokenを作成
  1. Settings → Developer settings → Personal access tokens → Tokens (classic)
  2. 「Generate new token (classic)」
  3. Note: Reading Log Backup
  4. Expiration: No expiration または 1 year
  5. Select scopes: ✅ repo (全てのrepo権限)
  6. 「Generate token」をクリック
  7. ⚠️ トークンをコピーして保存（二度と表示されません）
4 GitHub Actionsワークフローファイルをアップロード
  1. リポジトリページで「Add file」→「Create new file」
  2. ファイル名: .github/workflows/backup.yml
  3. ダウンロードした backup.yml の内容をコピー＆ペースト
  4. 「Commit new file」をクリック
5 GitHub Actionsを有効化
  1. リポジトリの「Actions」タブをクリック
  2. 「I understand my workflows, go ahead and enable them」をクリック
  3. これで毎週日曜日午前3時に自動実行されます
6 手動でバックアップをテスト
  1. 「Actions」タブ → 「📚 Reading Log Auto Backup」
  2. 「Run workflow」→「Run workflow」
  3. 実行が完了したら、backup/フォルダを確認

💾 実際のデータをバックアップ

⚠️ 重要
GitHub Actionsは自動的に「テンプレート」ファイルを作成します。実際の読書データをバックアップするには、手動でアップロードする必要があります。

📅 自動バックアップスケジュール

  • 実行頻度: 毎週日曜日 午前3時（日本時間）
  • 保存期間: 8週間（約2ヶ月）
  • 保存場所: backups/フォルダ
  • ファイル名形式: reading-log-backup_YYYY-MM-DD_HH-MM-SS.json
  • 古いファイルの削除: 8週間以上前のバックアップは自動削除

🔧 トラブルシューティング

GitHub Actionsが実行されない
  1. リポジトリの「Actions」タブでワークフローが有効になっているか確認
  2. 「Settings」→「Actions」→「General」でActionsが許可されているか確認
  3. cronスケジュールは次の実行まで時間がかかる場合があります（最大24時間）
バックアップファイルが空

GitHub Actionsは「テンプレート」ファイルのみを作成します。実際のデータは：

  1. 読書記録アプリで「データをエクスポート」
  2. 上記のフォームでGitHubにアップロード
  3. または、手動でリポジトリのbackups/フォルダにアップロード
古いバックアップが削除されない

ファイル名が正しい形式か確認してください：

reading-log-backup_YYYY-MM-DD_HH-MM-SS.json

この形式でない場合、自動削除の対象外になります。
